# Аналитический проект — Яндекс Афиша

## О проекте

Учебный проект по анализу данных сервиса Яндекс Афиша.

Яндекс Афиша — сервис, с помощью которого пользователи могут узнавать информацию о мероприятиях в разных городах и приобретать билеты.

В рамках проекта проведён анализ продаж, пользовательской активности, популярности мероприятий и различий в поведении пользователей мобильных и стационарных устройств.

Проект состоит из двух основных частей:

1. Анализ данных с помощью SQL и создание аналитического дашборда в Yandex DataLens.
2. Исследовательский анализ данных и статистическая проверка гипотез с помощью Python.

---

# 1. Цели проекта

- Рассчитать ключевые бизнес-метрики сервиса.
- Исследовать структуру выручки и заказов.
- Проанализировать динамику основных показателей.
- Выявить наиболее значимые сегменты по выручке и количеству заказов.
- Исследовать изменение пользовательской активности и предпочтений.
- Сравнить поведение пользователей мобильных и стационарных устройств.
- Проверить продуктовые гипотезы статистическими методами.
- Сформировать аналитические выводы и рекомендации для продуктовой команды.

# 2. Анализ данных с помощью SQL и Yandex DataLens

## Расчёт ключевых метрик

С помощью SQL рассчитаны основные показатели сервиса:

- общая выручка;
- количество заказов;
- средняя выручка с заказа;
- количество уникальных клиентов.

Расчёты выполнены отдельно для российских рублей и казахстанских тенге.

SQL-запросы находятся в директории [`sql`](https://github.com/galina-poruchikova/yandex-afisha-analytics/tree/main/sql).

## Анализ выручки по устройствам

Для заказов в рублях проведён анализ в разрезе типов устройств:

- общая выручка;
- количество заказов;
- средняя стоимость заказа;
- доля выручки каждого типа устройства.

## Анализ по типам мероприятий

Исследована структура заказов и выручки в разрезе типов мероприятий:

- выручка;
- количество заказов;
- средняя стоимость заказа;
- количество уникальных мероприятий;
- среднее количество билетов в заказе;
- средняя выручка с одного билета;
- доля выручки.

## Анализ динамики

Рассчитана недельная динамика:

- выручки;
- количества заказов;
- количества уникальных клиентов;
- средней стоимости заказа.

## Топ регионов

Выделены 7 регионов с наибольшей выручкой и рассчитаны:

- выручка;
- количество заказов;
- количество уникальных клиентов;
- количество проданных билетов;
- средняя выручка с одного билета.

- популярность мероприятий;

# 4. Анализ данных в Python

Во второй части проекта проведён полный цикл анализа данных сервиса Яндекс Афиша: от загрузки и первичного знакомства с данными до предобработки, исследовательского анализа и статистической проверки гипотез.

## 4.1. Загрузка и знакомство с данными

- Загрузка и объединение необходимых наборов данных.
- Изучение структуры и объёма данных.
- Проверка типов данных.
- Первичная оценка качества и корректности данных.
- Формирование предварительных выводов и плана предобработки.

## 4.2. Предобработка данных

- Проверка данных на пропуски.
- Анализ категориальных и количественных значений.
- Выявление и обработка выбросов в выручке и количестве билетов.
- Раздельный анализ данных в рублях и тенге.
- Проверка явных и неявных дубликатов.
- Преобразование типов данных, включая даты и время.
- Объединение наборов данных.
- Создание новых признаков:
  - `revenue_rub` — выручка с заказа в российских рублях;
  - `one_ticket_revenue_rub` — выручка с одного билета;
  - `month` — месяц оформления заказа;
  - `season` — сезон оформления заказа.
- Контроль количества данных после фильтрации и преобразований.

## 4.3. Исследовательский анализ данных (EDA)

- Анализ распределения заказов по основным сегментам.
- Исследование сезонных изменений пользовательского поведения.
- Сравнение активности пользователей летом и осенью.
- Анализ распределения заказов по типам устройств.
- Исследование возрастных рейтингов мероприятий.
- Анализ выручки с одного билета в зависимости от типа мероприятия.
- Анализ динамики заказов и пользовательской активности по дням.
- Исследование недельной активности пользователей.
- Анализ популярных регионов, мероприятий и билетных партнёров.
- Визуализация результатов с помощью Matplotlib.

## 4.4. Статистический анализ и проверка гипотез

Проверены две гипотезы о различиях в поведении пользователей мобильных и стационарных устройств.

### Гипотеза 1 — среднее количество заказов на пользователя

- Формирование непересекающихся групп пользователей.
- Исключение пользователей, использовавших оба типа устройств.
- Расчёт количества заказов на пользователя.
- Обработка выбросов методом IQR.
- Сравнение средних значений в мобильной и стационарной группах.
- Проверка гипотезы с помощью одностороннего t-теста Уэлча.

### Гипотеза 2 — среднее время между заказами

- Формирование непересекающихся групп пользователей.
- Расчёт количества дней между последовательными заказами.
- Исключение наблюдений без предыдущего заказа.
- Обработка выбросов методом IQR.
- Сравнение среднего времени между заказами.
- Проверка гипотезы с помощью одностороннего t-теста Уэлча.

### Результаты статистического анализа

Статистическая проверка позволила оценить, существуют ли значимые различия в поведении пользователей мобильных и стационарных устройств.
