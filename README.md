# Анализ данных сервиса Яндекс Афиша

Учебный дипломный проект в рамках профессиональной переподготовки «Аналитик данных».

## О проекте

Яндекс Афиша — сервис, с помощью которого пользователи находят информацию о мероприятиях и покупают билеты.

В рамках проекта необходимо было исследовать динамику продаж и выручки, пользовательскую активность, популярность мероприятий, организаторов и площадок, а также сравнить поведение пользователей мобильных и стационарных устройств.

Проект состоит из двух частей:

1. Анализ данных с помощью SQL и разработка аналитического дашборда в Yandex DataLens.
2. Исследовательский анализ данных и проверка продуктовых гипотез с помощью Python.

---

## Цели исследования

- оценить основные бизнес-показатели сервиса;
- изучить динамику продаж и выручки;
- определить наиболее прибыльные сегменты;
- исследовать популярность мероприятий, организаторов и площадок;
- сравнить поведение пользователей разных типов устройств;
- проверить статистические гипотезы;
- сформировать практические рекомендации для продуктовой команды.

---

# 1. Анализ данных с помощью SQL

На первом этапе были рассчитаны ключевые бизнес-метрики сервиса и исследована структура продаж.

## Рассчитанные метрики

- общая выручка;
- количество заказов;
- средняя стоимость заказа;
- количество уникальных клиентов;
- количество проданных билетов;
- средняя стоимость билета;
- доля выручки по сегментам.

## Проведённый анализ

### Выручка и заказы

Рассчитаны основные показатели сервиса в разрезе валют.

### Выручка по типам устройств

Исследовано распределение выручки и количества заказов между типами устройств.

### Выручка по типам мероприятий

Проведён анализ:

- количества заказов;
- общей выручки;
- средней стоимости заказа;
- количества уникальных мероприятий;
- среднего количества билетов в заказе;
- средней выручки с одного билета;
- доли выручки.

### Динамика показателей

Рассчитана недельная динамика:

- выручки;
- количества заказов;
- количества уникальных клиентов;
- средней стоимости заказа.

### Региональный анализ

Определены топ-7 регионов по общей выручке и рассчитаны основные показатели продаж для каждого региона.

## Используемые SQL-инструменты

- `SELECT`
- `WHERE`
- `GROUP BY`
- `ORDER BY`
- агрегатные функции
- `COUNT`
- `COUNT DISTINCT`

- расчёт производных метрик и долей
