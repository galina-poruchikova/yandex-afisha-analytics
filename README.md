# Анализ данных сервиса Яндекс Афиша

Учебный аналитический проект, выполненный в рамках профессиональной переподготовки «Аналитик данных».

## Цель проекта

Провести анализ данных сервиса Яндекс Афиша для оценки динамики продаж,
выручки, активности пользователей и различий в поведении клиентов
мобильных и стационарных устройств.

Проект состоит из двух частей:

- анализ данных с помощью SQL и разработка дашборда в Yandex DataLens;
- исследовательский анализ данных и проверка гипотез с помощью Python.
